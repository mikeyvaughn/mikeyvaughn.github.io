# Mikey Vaughn

Personal portfolio featuring labor leadership, advocacy, community involvement, campaigns, and digital organizing.

This static website is served by GitHub Pages from the main branch at the repository root. No build step is required. Open index.html locally or serve the folder with a static web server for previews.

Maintain index.html, union-leadership.html, styles.css, favicon.svg, and the assets folder together. Photography credits appear in the site footer. Organization logos identify the organizations discussed and retain their own ownership. Newsreader and Bootstrap Icons license notices are included in assets.
